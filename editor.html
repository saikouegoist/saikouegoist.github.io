  1. Fill the form below and press save article — it is only staged, nothing on disk changes yet.
  2. Press download current .md and put the file in articles/. Then press download data/articles.js and overwrite data/articles.js. You need both — the .md alone shows nothing.
  3. Refresh index.html to preview. To change or remove later, use edit / delete in existing articles below, then download data/articles.js again.
  4. Push to publish.
