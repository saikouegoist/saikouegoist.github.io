how to add / remove articles
  1. Fill the form below and press save article — it is only staged, nothing on disk changes yet.
  2. Press download current .md and put the file in articles/. Then press download data/articles.js and overwrite data/articles.js. You need both — the .md alone shows nothing.
  3. Refresh index.html to preview. To change or remove later, use edit / delete in existing articles below, then download data/articles.js again.
  4. Push to publish.

how to add / remove notes
  1. Compose your note and attach up to 10 images. Choosing files records them as notes/images/<filename> (paths, never embedded) — the 1st image becomes the primary photo, like Twitter.
  2. Press save note — it stages it and immediately updates your preview and local timeline.
  3. Copy the image file(s) shown in the “copy these files” note into the notes/images/ folder, then press download data/notes.js (or copy code) and overwrite data/notes.js.
  4. Open index.html#/notes to view your distraction-free timeline without sidebars!
